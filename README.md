- Nəticə: `out/maqayis/NNNN.json` (ərəbcə + az + mənbə istinadı). Gediş: `state.json`.
- Hər gün 08:15 UTC (11:15 Riyad) Gemini pulsuz limiti bitənə və ya 45 dəq. dolana qədər işləyir.
